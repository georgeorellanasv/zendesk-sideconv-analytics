Las dos cosas que hay que arreglar
The two things to fix
Cuello 1 — Cobertura del sistema
Bottleneck 1 — System coverage
13%
El trigger solo avisó en 22 de 163 llamadas. En el resto, el agente nunca recibió la alerta. Solución: activar el trigger para todos los grupos (en rollout). El techo de adherencia no puede superar este número.
The trigger only alerted on 22 of 163 calls. In the rest, the agent never got the alert. Fix: activate the trigger for all groups (in rollout). Adherence can't exceed this number.
Cuello 2 — Respuesta del agente
Bottleneck 2 — Agent response
13.6%
Aún cuando el sistema SÍ avisó (22 llamadas), el agente marcó el motivo correcto solo 3 veces. Solución: entrenamiento — que al ver la nota interna, el agente seleccione el RFC y mande la confirmación.
Even when the system DID alert (22 calls), the agent set the correct reason only 3 times. Fix: training — when the internal note appears, the agent should select the RFC and send the confirmation.
